🔒 Security Deposit

  • Security deposit = same amount as dress (e.g. ₱500 dress + ₱500 deposit)
  • Paid before pickup
  • Fully refundable after return 💸

📦 Delivery & Return

  • Renter arranges delivery/pickup (Lalamove pooling recommended for lower rates)
  • Pickup: day before event
  • Return: day after event
  • Deposit refunded after dress return 💸
